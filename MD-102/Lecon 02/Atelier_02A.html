Atelier 02A – Le centre d'inscription et Windows

🎯 Mission : vérifier comment votre tenant inscrit les PC, puis bloquer les PC Windows personnels.

⏱ 20 min 🔑 Admin Intune ou Admin général ⚠️ Tenant de test uniquement

Leçon associée : Leçon 02A. Les repères A3, A6… renvoient à ses diapositives (bouton ☰ Sommaire du lecteur).

Toutes les étapes partent de intune.microsoft.com › Appareils › Intégration de l'appareil › Inscription.

① La fenêtre unique

Appareils › Intégration de l'appareil › Inscription

✅ Vous devez voir : 6 onglets : Windows · Apple · Android · Identifiants d'appareils d'entreprise · Gestionnaires d'inscription d'appareils · Monitorer.

🛠 Ça coince ?

« Inscription » se trouve sous le titre Intégration de l'appareil du menu de gauche.
↩ Revoir A3 · La fenêtre unique

② Les réglages de l'inscription automatique

onglet Windows › Inscription automatique

✅ Vous devez voir : l'étendue MDM (« Gestion des données de référence »), l'interrupteur « Désactivez l'inscription MDM… » et l'étendue MAM (« Protection des informations Windows (WIP) »).

📝 Notez les 3 valeurs. Ne modifiez rien.

🛠 Ça coince ?

Vous ne trouvez pas « MDM » ? La console le traduit par « Gestion des données de référence ».
↩ Revoir A5 · Inscription automatique

💡 Pourquoi ?

Sur Aucun, les PC se joignent à Entra ID mais n'arrivent jamais dans Intune. Partiel = groupes choisis (pilote), Tout = production.
↩ Revoir A6 · Étendue MDM et A7 · MAM et interrupteur

③ La restriction par défaut

onglet Windows › Restriction de la plateforme d'appareils → page Restrictions d'inscription, onglet Restrictions Windows

✅ Vous devez voir : une seule ligne : priorité « Par défaut », nom « Tous les utilisateurs ». Ouvrez-la › Propriétés : Windows (MDM) et Appareils personnels sur « Autoriser ».

🛠 Ça coince ?

La page a un onglet par plateforme : vérifiez que vous êtes sur Restrictions Windows.
↩ Revoir A9 · Restrictions

Restrictions d'inscription › Restrictions Windows › Créer une restriction

✅ Vous devez voir : votre restriction au-dessus de « Tous les utilisateurs ». 📝 Notez sa priorité.

🛠 Ça coince ?

Vous voulez supprimer la restriction par défaut et le bouton est grisé ? C'est normal : on peut seulement la modifier.
↩ Revoir A9 · Restrictions

💡 Pourquoi ?

Le plus petit numéro gagne. Autopilot, les identifiants d'entreprise, le DEM et la cogestion passent quand même.
↩ Revoir A9 · Restrictions

⑤ La limite d'appareils Intune

onglet Windows › Restriction du nombre limite d'appareils

✅ Vous devez voir : « All users and all devices ». 📝 Notez la limite.

🛠 Ça coince ?

Ne la confondez pas avec la limite d'Entra ID (Entra › Appareils › Paramètres des appareils).
↩ Revoir A10 · Deux limites

⑥ Les identifiants d'entreprise

onglet Identifiants d'appareils d'entreprise › Ajouter

✅ Vous devez voir : 2 choix : Charger un fichier CSV · Entrer manuellement. Fermez sans rien ajouter.

💡 Pourquoi ?

Un appareil déclaré ici est considéré comme appartenant à l'entreprise : votre restriction de l'étape ④ ne le bloque pas.
↩ Revoir A9 · Restrictions
