Atelier 09 – Des données propres dès la saisie, à vous de jouer (20 min)

La synthèse de Karim compte 51 devis en janvier, alors que Sophie en a signé 60. Vous allez trouver les fautes de frappe, les corriger, et empêcher qu'elles reviennent.

Fichier : votre copie de Excel_9_Validation_donnees_devis.xlsx (à télécharger juste sous cette page) : feuilles Devis (60 devis, lignes 2 à 61), Listes (les valeurs autorisées) et Synthèse. Durée : 20 minutes.

Gardez le fichier ouvert : le quiz de contrôle, en bas de la section, vérifie que vous avez compris chaque geste.

Étape 1 – Constater le problème

Faites : ouvrez la feuille Synthèse.

Vous devez voir : Accepté 35, Refusé 14, En attente 2 : Total compté 51, alors que la liste contient 60 devis.

Pourquoi : NB.SI ne compte que le texte exact (les majuscules exceptées). « Acepté », « Refuse » ou « accepté » suivi d'une espace ne sont pas comptés.

Étape 2 – La liste déroulante

Faites : feuille Devis, sélectionnez I2:I61. Données → Validation des données. Autoriser : Liste. Source : =Listes!$A$2:$A$4 → OK.

Vous devez voir : une petite flèche quand vous cliquez dans une cellule de la colonne Statut, avec les trois statuts.

Si ça ne marche pas : la liste est vide plus bas dans la colonne ? Il manque les $ dans la source.

Étape 3 – Guider et refuser

Faites : I2:I61 toujours sélectionné, rouvrez la Validation des données. Onglet Message de saisie : « Choisissez le statut dans la liste ». Onglet Alerte d'erreur : style Arrêt, message « Statut inconnu : utilisez la liste » → OK. Tapez « Acepté » en I2.

Vous devez voir : la bulle d'aide en cliquant dans la cellule, puis votre message d'erreur : la saisie est refusée. Cliquez sur Annuler.

Étape 4 – Entourer les erreurs déjà présentes

Faites : Données → flèche de Validation des données → Entourer les données non valides.

Vous devez voir : 9 cercles rouges dans la colonne Statut (par exemple I5 « Acepté », I10 « Refuse », I49 « OK »).

Pourquoi : la règle ne contrôle que les nouvelles saisies ; les fautes déjà présentes restent en place.

Étape 5 – Corriger avec la liste

Faites : pour chaque cellule entourée, choisissez le bon statut dans la liste (« Acepté », « accepté », « Acceptée » et « OK » → Accepté ; « Refuse » et « Refusé » suivi d'une espace → Refusé ; « En atente » et « en attente » → En attente). Revenez sur Synthèse.

Vous devez voir : les cercles disparaissent un à un ; la synthèse affiche Accepté 39, Refusé 17, En attente 4, Total compté 60.

Étape 6 – Des montants positifs

Faites : sélectionnez H2:H61. Validation des données : Autoriser Décimal, Données : supérieure à, Minimum : 0 → OK. Puis Entourer les données non valides.

Vous devez voir : un cercle en H31 : le devis D-2026-030 à −5 290 €. Corrigez-le en 5 290.

Étape 7 – Le point faible

Faites : tapez OK dans une cellule libre (K2), copiez-la, puis collez-la en I3. Cliquez ensuite sur I3.

Vous devez voir : le collage est passé sans aucun message, et I3 n'a plus de flèche : elle a perdu sa règle. Même « Entourer les données non valides » ne la signale plus. Annulez avec Ctrl+Z, puis effacez K2.

Pourquoi : le copier-coller contourne et écrase la validation. Pour coller dans une colonne validée, utilisez Collage spécial → Valeurs, puis relancez « Entourer les données non valides ».
