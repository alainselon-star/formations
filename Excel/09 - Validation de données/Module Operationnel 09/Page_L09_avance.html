Pour aller plus loin – Les bons d'intervention (facultatif, 30 min)

Vous avez réussi l'atelier ? Ce défi se fait dans le vrai Excel, sur un fichier à télécharger. Il est moins guidé. Les techniciens saisissent leurs bons d'intervention dans un tableau partagé, sans aucune règle. Résultat : des villes mal écrites, des durées négatives, des dates dans un autre siècle et des bons saisis deux fois. Vous allez poser les règles, puis nettoyer ce qui est déjà là.

Le fichier : Excel_9_avance_bons_intervention.xlsx, juste sous cette page. Feuille Interventions : 82 lignes. Feuille Listes : les villes autorisées. La feuille Contrôle vérifie les données une fois corrigées. Une formule ne peut pas voir si une règle de validation existe : pour les règles elles-mêmes, comparez avec le corrigé.

La méthode, pour chaque mission : sélectionnez la colonne, posez la règle (Données → Validation des données), puis Données → Validation des données ▾ → Entourer les données non valides, et corrigez chaque cercle.

Mission 1 – Les villes (colonne C)

Le besoin : seulement les six villes de la feuille Listes, avec une liste déroulante et un refus en cas de faute.

Un indice

Liste, source =Listes!$A$2:$A$7, alerte de style Arrêt. Cinq cercles : des fautes de frappe et une espace invisible après « Senlis ».

Mission 2 – Les durées (colonne E)

Le besoin : un nombre entier d'heures, de 1 à 10.

Un indice

Nombre entier, compris entre 1 et 10. Les cercles montrent des durées négatives : un signe moins tapé par erreur. Retirez-le.

Mission 3 – Les dates (colonne B)

Le besoin : uniquement des dates de 2026.

Un indice

Date, comprise entre le 01/01/2026 et le 31/12/2026. Trois années ont été mal tapées : gardez le jour et le mois, remettez 2026.

Mission 4 – Les doublons (colonne A)

Le besoin : un numéro d'intervention ne doit apparaître qu'une fois. Aucune règle toute faite ne le permet : il faut une règle personnalisée, avec une formule.

Un indice

Sélectionnez A2:A83, Autoriser : Personnalisé, formule =NB.SI($A$2:$A$83;A2)=1 : « ce numéro n'apparaît qu'une fois dans la colonne ». Entourer marque les deux exemplaires de chaque doublon : les lignes sont identiques, supprimez l'une des deux (clic droit sur le numéro de ligne → Supprimer).

Vérifier et se corriger

Ouvrez la feuille Contrôle : 4 ✓ sur 4, c'est gagné. Testez ensuite vos règles : tapez « Compiegne » dans une ville, ou un numéro qui existe déjà. Le corrigé, sous cette page, contient les données propres et les quatre règles en place.
