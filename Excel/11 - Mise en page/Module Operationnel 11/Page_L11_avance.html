Pour aller plus loin – Le classeur prêt à imprimer (facultatif, 30 min)

Vous avez réussi l'atelier ? Ce défi se fait dans le vrai Excel, sur un fichier à télécharger. Il est moins guidé. La banque veut maintenant la liste des clients par commercial, chaque commercial sur ses propres pages, et un seul PDF avec tout le classeur, à l'en-tête de l'Atelier Martin.

Le fichier : Excel_11_avance_classeur_imprimable.xlsx, juste sous cette page. Feuilles Clients et Récap, comme dans l'atelier, sans aucun réglage. Feuille Liste de contrôle : une formule ne peut pas lire les réglages d'impression, alors vous cochez vous-même chaque point, en vérifiant dans l'aperçu (Ctrl+P). Seul le tri est vérifié automatiquement.

Mission 1 – Une page par commercial (feuille Clients)

Le besoin : la liste triée par commercial, chaque commercial commençant sur une nouvelle page. Les titres en haut de chaque page, toutes les colonnes sur la largeur.

Un indice

Triez par Commercial (Données → Trier). Reprenez les réglages de l'atelier : Imprimer les titres $1:$1, Paysage, Largeur 1 page. Puis cliquez sur la première ligne de Sophie (le numéro de ligne, à gauche) → Mise en page → Sauts de page → Insérer un saut de page. Même chose sur la première ligne de Thomas. Vérifiez dans Affichage → Aperçu des sauts de page.

Mission 2 – En-tête et pied de page sur les deux feuilles

Le besoin : en-tête « Atelier Martin » à gauche et la date à droite ; pied de page « Page n sur N » au centre et le nom de la feuille à droite. Sur les deux feuilles, en une seule fois.

Un indice

Groupez les feuilles (clic sur l'onglet Clients, Ctrl+clic sur Récap : leçon 16), puis Mise en page → lanceur du groupe (petite flèche) → onglet En-tête/Pied de page → En-tête personnalisé et Pied de page personnalisé. Les boutons insèrent la date (&[Date]), le numéro de page et le nom de l'onglet. N'oubliez pas de dissocier les feuilles ensuite.

Mission 3 – Un récapitulatif soigné (feuille Récap)

Le besoin : seulement le tableau A1:F17, centré horizontalement sur la page.

Un indice

Zone d'impression A1:F17 (comme dans l'atelier). Puis Mise en page → Marges → Marges personnalisées → cochez Horizontalement sous « Centrer sur la page ».

Mission 4 – Le PDF pour la banque

Le besoin : un seul fichier PDF avec les deux feuilles.

Un indice

Fichier → Exporter → Créer un document PDF/XPS → Options → Classeur entier → OK → Publier. Comparez avec le PDF attendu, sous cette page : environ 10 pages, Julie, Sophie et Thomas chacun sur ses pages, puis le récapitulatif centré.

Vérifier et se corriger

Feuille Liste de contrôle : tapez x en face de chaque point vérifié, 8 sur 8. Le corrigé contient tous les réglages (ouvrez son aperçu avec Ctrl+P), et le PDF attendu montre le résultat. Ouvrez-les seulement après avoir vraiment essayé.
