# Formations — Académie numérique

Dépôt privé des sources de formation d'Alain (cours Moodle « Académie numérique »).

## Organisation

La structure reprend celle du dossier `Documents\Formation bureautique` du PC :

| Dossier | Contenu |
|---|---|
| `Excel/` | Parcours Excel (Opérationnel, TCD, test de positionnement) |
| `Power BI/` | Parcours Power BI Desktop |
| `KPI/` | Cours KPI – les fondamentaux |
| `MD-102/` | Parcours MD-102 (Intune / Endpoint) |
| `Word/`, `PowerPoint/`, `Outlook/` | Bureautique |
| `IA/` | Contenus IA |
| `LMS/` | Ressources Moodle |
| `Articulate*/` | Sources Storyline (archives, licence expirée) |
| `Production vidéo/` | Scripts et ressources vidéo (sans les vidéos) |

## Règles

- **Aucune donnée d'élève** dans ce dépôt.
- Seule la **dernière version** de chaque paquet SCORM est conservée ; l'historique Git garde les précédentes.
- Les dossiers de publication Storyline (`html5/`, `mobile/`, `story_content/`) et les vidéos ne sont pas versionnés.

## Synchronisation

- **PC** : GitHub Desktop → *Fetch / Pull* pour récupérer les nouveautés.
- **Claude** : travaille directement sur ce dépôt, même PC éteint.
- **VPS** (à venir) : récupération automatique pour publication dans Moodle.
